# عيادة بياض الثلج — نظام إدارة عيادة الأسنان

تطبيق كمبيوتر مكتبي مبني بـ Electron لإدارة عيادة **بياض الثلج**.

## الوظائف الحالية
- لوحة تحكم وإحصاءات سريعة.
- إدارة المرضى والبحث في السجل.
- إدارة المواعيد.
- تسجيل العلاجات وتكاليفها.
- سجل المدفوعات والإيرادات.
- تخزين البيانات محلياً على جهاز الكمبيوتر عبر localStorage.
- واجهة عربية RTL.

## التشغيل

بعد تثبيت Node.js:

```bash
npm install
npm start
```

## ملاحظات
هذه النسخة هي الأساس الأولي للتطبيق. يمكن لاحقاً إضافة قاعدة بيانات SQLite، نسخ احتياطي واستعادة، طباعة الفواتير، ملف طبي متكامل لكل مريض، المستخدمين والصلاحيات، وتقارير شهرية.
